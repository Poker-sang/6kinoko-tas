# 6kinoko TAS

C# / .NET 10 + Avalonia 12 的《魔理沙与六个蘑菇》TAS 编辑器，配合 [6kinoko-modern](https://github.com/Poker-sang/6kinoko-modern) 使用。不含游戏程序和原版 DAT。

首版 TAS 工作流已于 2026-09-30 收尾，用户已确认新版不限速定位效果良好。
当前交付版本、验证记录及保留限制见 [首版收尾](docs/first-version-closeout.md)。

## 使用

安装 .NET 10，构建或下载编辑器。首次新建/打开录制时选择支持 TAS 的 kinoko_modern_gpu.exe；游戏目录需自备原版三个 DAT。

- 新建录制、打开录制、保存单文件 .krec（含初始存档和书签）。兼容旧 KINORPL1 录制。
- 独立游戏窗口或可选内嵌预览；暂停、逐帧、从头重播、关闭后重新启动游戏。
- 横向实时输入时间轴，播放游标、跟随最新帧、可命名书签。
- 帧号单击选中，双击定位；右键添加书签。回退目前从头重播模拟。
- 定位后切换录制，覆盖当前帧之后的内容；旧来源保留为内部恢复副本。
- 新录制首次保存选择 .krec 路径，后续保存沿用；打开 .krec 后保存到该文件。“另存为录制…”始终选择路径。内部 sessions 工作文件不必随录制分享。
- 保存在帧边界暂停，保留当前游戏进程，可继续录制；Ctrl+S 保存，Ctrl+Shift+S 另存为。实时录制保存需要支持 snapshot-v1 的新版游戏。

游戏窗口 F9 播放/暂停、F10 前进一帧。工具栏“…”包含更换游戏和内嵌预览。
关闭“录制”开关后可修改时间轴输入格或区间，点击帧工具中的“应用修改”（F5）。
输入格支持水平拖动绘制，同一笔可用 Ctrl+Z 整体撤销。
帧编辑栏“…”可按数量插入/追加空白帧，或删除起止区间；书签随帧移动，撤销可恢复被删除的书签。
引擎从初始存档重播并验证修改前的前段，执行新输入生成校验值，再完整回放验证。
只有全部成功才替换当前录制；之后可保存为单文件 .krec。.ktas 仍用于暂存未执行的草稿。
播放栏“…”中的“恢复上次覆盖”（Ctrl+Shift+Z）可恢复本次编辑器会话内的旧录制、位置、书签与草稿。
定位/模拟显示进度，Esc 或播放栏“…”中的取消可中止；失败不会采用未验证的结果。
编辑器获得焦点时：F9 播放/暂停、F10 逐帧、F8 录制、F6 书签、F5 应用修改。
独立游戏窗口仍支持 F9/F10；其他编辑快捷键在 TAS 窗口使用。

播放栏速度选择支持 0.25×、0.5×、1×、2×、4×。倍速只改变调度，逻辑始终按每秒 60 帧的模拟时间运行，声音保持原播放速度。
新版引擎按不限速执行定位、重新模拟和验证，定位期间静音，完成后保持选择的播放速度；实际速度受机器性能限制。旧版支持倍速的引擎使用 4×兼容路径。
变长编辑需要支持 edits-v2，倍速需要 pacing-v1；旧版游戏会明确报错。请在文件栏“…”更换游戏程序后重新打开录制。
完整快照和瞬时倒带尚未实现，回退仍从头模拟。
新封装 .krec 由本编辑器解包后交给游戏，游戏旧 CLI 不直接识别该封装。

## 开发与检查

```powershell
dotnet build KinokoTAS.slnx -c Release
dotnet run --project src/KinokoTAS.App
dotnet run --project tests/KinokoTAS.Checks -c Release -- artifacts/checks-unique
```

检查使用模拟引擎和 Avalonia 无窗口后端，不运行真实游戏。当前主要验证 Windows；其他平台编辑器运行未验证。
详细记录见 docs/，其中旧版交接路径为历史记录。
