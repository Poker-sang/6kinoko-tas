# 输入编辑闭环收尾

## 使用

游戏：C:/WorkSpace/6kinoko-modern/runtime-builds/modern-x64-tas-edits-02/kinoko_modern_gpu.exe
编辑器：artifacts/windows-editor-17/KinokoTAS.App.exe（.NET 10）
游戏源码 2df218fb；编辑器源码 edc309f。三个 DAT 已复制到游戏旁并验证 SHA256。

1. 文件栏“…”更换为新版游戏程序，然后打开录制。
2. 如正在录制，关闭录制开关；修改时间轴输入格或帧工具中的区间。
3. 展开“编辑帧输入”，点击“应用修改”（F5）。
4. 等待“重新模拟”和“回放验证”两阶段成功，保存 .krec。
5. 播放栏“…”的“恢复上次覆盖”（Ctrl+Shift+Z）可恢复旧录制、位置、书签和草稿。

旧 .krec/.ktas 仍可打开。未应用草稿不能悄悄另存成不含修改的 .krec，
需先应用或另存 .ktas。原始文件不会改写。恢复记录在当前会话内可用；
候选结果、失败产物和旧分支都保留在 sessions 中。

编辑器焦点：F9 播放/暂停，F10 逐帧，F8 录制，F6 书签，F5 应用修改。
独立游戏窗口保持 F9/F10，其余快捷键回到编辑器使用。
定位显示当前/目标帧；模拟显示阶段和比例。Esc 或播放栏“…”的取消按钮可中止。
取消定位会在当前边界暂停；取消模拟/验证保持原会话与草稿。

## 实现与边界

KTASED01 文件包含总帧数、首次修改帧和各帧的 19 位动作掩码，均明确小端编码。
游戏启动公布 edits-v1 能力；老引擎不被静默当作成功。
初始存档沿用原录制副本；从开头验证旧输入前段，在首次修改帧自动接管，
严格按脚本输入执行。包括第 0 帧，且生成阶段不混入键盘输入。
持有时长、释放边沿、随机数及检查点由真实游戏运行时重新生成。
候选结果完成后，另开干净进程完整回放校验。只在全部成功后接替旧会话。
完整快照和倍速未包含；模拟和验证耗时随录像长度增长。
