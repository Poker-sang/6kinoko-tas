# 简化流程与独立游戏窗口

编辑器：artifacts/windows-editor-06/KinokoTAS.App.exe（源码 04324e8）。
配套游戏：C:/WorkSpace/6kinoko-modern/runtime-builds/modern-x64-tas-window-02/kinoko_modern_gpu.exe（源码 4ac9775）。
本版独立窗口必须使用此配套游戏，旧版不认识 --tas-window。

## 开始

- 新建录制：选择游戏程序后直接建立空存档录制，首帧暂停。
- 打开录制：选择 .krec 或 .ktas 后自动连接游戏，不再单独点击连接按钮。
- 游戏路径保存在 LocalAppData/KinokoTAS/settings.json，下次启动自动使用；“更换游戏程序”可以重新选择。
- 默认独立游戏窗口。需要旧的内嵌预览时，在开始前勾选“内嵌预览”。活动会话中不可切换。
- 首次打开旧录制可能需要选择 initial 初始存档目录并确认逐帧验证。

## 操作

点击播放后在游戏窗口操作。F9 播放/暂停，F10 前进一帧（可同时按住动作键）。
方向键移动；Z 跳跃/确认，X 攻击/加速/搬运，A 游戏暂停/副确认，C 道具。
Space 仅跳跃，Enter 仅确认，Esc 游戏暂停。F9 控制工具暂停，A/Esc 控制游戏菜单。
切换游戏和编辑器窗口不会自动暂停；离开游戏窗口会释放它的键盘输入。
独立模式切到其他应用同样不会自动暂停，请先按 F9 或点击暂停。

点击时间轴帧号或输入帧号定位，回退仍需从头重播。“从这里继续录制”保存已有前缀并开始实时输入。
“结束录制并保存”完成新文件后自动载入；文件在编辑器旁 sessions/ 内，原始录制和普通存档不变。
接管后需先保存，再打开新录制进行回退。

输入时间轴格子和区间修改属于“输入草稿”，不改变游戏回放，尚未支持编辑后重新模拟。
.krec 是可回放录制，.ktas 是保存这些编辑意图的项目。
