# 横向时间轴与紧凑布局

编辑器 artifacts/windows-editor-08/KinokoTAS.App.exe，源码 e833d6d。
游戏沿用 modern-x64-tas-window-02，无需更换。

时间轴横向为帧、纵向为 19 个动作，格子 12×17。顶行点击定位帧，动作格点击修改草稿；滚轮及底部水平滚动条浏览帧。
顶栏移除品牌标题，游戏路径、内嵌预览及文件 CommandBar 合成一行。长路径省略显示，悬停查看完整路径。

Windows 下为当前会话拥有的游戏窗口设置 TAS 窗口为 owner，使游戏保持在 TAS 上方，而非全局置顶。
仅用于本编辑器启动的独立游戏进程，重播重启后重新设置。Avalonia 无跨进程 owner 接口，故使用小型 Windows 适配器；其他平台不宣称支持。
Windows owner 关系也意味着最小化 TAS 会连带隐藏游戏窗口。实际双窗口层级行为尚待用户验证。

验证：build-23 构建零警告/错误，checks-23 所有模拟引擎及 UI 回归通过，截图检查横向时间轴与单行顶栏。
build-24 构建/发布成功，包含进程重启后重置窗口追踪的小修正。未运行实际游戏或验证原生窗口层级。

文件说明：.krec 保存录制输入与校验信息，initial/ 保存初始存档；当前不是完整单文件格式。
.bookmarks.json 保存书签，可删但会丢书签。bridge/ 和状态文本为会话运行通信/诊断文件，仅关闭会话后可清理。
其他 session JSON 用于身份/初始文件校验，不能把所有 JSON 当作缓存删除。所有已有产物继续保留。
.ktas 仍用于输入草稿项目，普通录制无需使用。未来单文件封装需要把初始存档和书签纳入格式，目前未实现。
