# 命令栏、保存位置与帧书签

编辑器：artifacts/windows-editor-07/KinokoTAS.App.exe（源码 f776c62）。
游戏仍用 C:/WorkSpace/6kinoko-modern/runtime-builds/modern-x64-tas-window-02/kinoko_modern_gpu.exe，无需更换。

## 界面

使用 Avalonia 12 CommandBar + FluentIcons.Avalonia 2.1.341。
顶部是文件命令：新建录制、打开录制、保存录制。更换游戏、保存输入草稿项目、仅导出原始录制收在顶部“…”内。
当前游戏完整路径常驻顶部，沿用之前已记住的路径。
画面区域只放播放控制；时间轴及右栏负责帧定位、书签和输入编辑。
输入草稿工具默认折叠，其修改仍不直接影响游戏回放。

## 保存录制

顶部“保存录制…”或 Ctrl+S：先暂停，选择保存目录后结束并保存录制。
选择取消则保留当前暂停会话，可继续播放。
保存目录内新建带时间和唯一编号的录制文件夹，包含 session.krec、initial/ 初始存档及 session.krec.bookmarks.json。
不会覆盖原录制或普通游戏存档。请一起移动整个录制文件夹。
完整保存路径常驻底部，“打开保存目录”直接打开该位置。
关闭/切换会话仍保留编辑器 sessions 下的自动备份。
输入草稿单独从文件栏“…”保存 .ktas；保存录制不把输入草稿冒充为有效回放。

## 书签 / 重点

输入名称并点书签栏的“标记”，会暂停并标记实际已完成的当前游戏帧。
未连接游戏时标记时间轴选中的帧。书签自动保存，重新打开同一录制可恢复；手动保存录制时随文件一起保存。
选中书签点“返回”，自动定位。录制中返回会先保留完整当前分支，再打开它重播到目标帧；之后可点“从这里继续录制”。
书签是位置标记，不是内存快照；回退仍需要从头重播。不会丢掉回退前书签之后的操作。
删除位于书签命令栏“…”内。
