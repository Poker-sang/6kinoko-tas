# 单文件录制

编辑器 artifacts/windows-editor-09/KinokoTAS.App.exe，源码 240e4ba；游戏沿用 modern-x64-tas-window-02。
内嵌预览已使用带图标的 CommandBarToggleButton。

“保存录制…”现在选择文件名并写出单个压缩 .krec，包含原始回放、初始存档和书签，不在目标旁创建 initial/ 或 JSON。
新包采用 ZIP 容器、recording.json version 1 清单和逐文件 SHA256；内部 replay.krec 仍为 KINORPL1。
读取校验完整回放及文件哈希，拒绝多余条目、重复路径、非允许存档名和过大解压内容。
普通打开流程无需再选择初始存档目录。旧原始 .krec 和 .ktas 仍可打开；旧录制另存后即可转为新包。
.ktas 仍是输入草稿项目，不是已重新模拟的回放。

新包通过本版编辑器播放：编辑器在内部 sessions/ 解包并向游戏传入原 KINORPL1。
旧编辑器和游戏 CLI 本身不能直接解析 ZIP 封装；旧格式导出仍在文件栏“…”的“仅导出原始录制”中。
运行会话仍有通信/日志文件，属于内部工作文件，不属于需要分享的录制；按项目要求保留全部历史产物。
新包保存后仅需分享这个 .krec（接收方仍需游戏 EXE 与正版 DAT）。后续新增书签需再次保存录制才能随新文件分享；本机自动缓存不修改原始文件。

原有窗口、逐帧、书签返回和保留原分支回归通过；模拟引擎测试，不声称实际游戏运行验证。
