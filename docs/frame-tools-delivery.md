## 使用

播放栏速度选择支持 0.25×、0.5×、1×、2×、4×，暂停与播放时都可调整。
切换、定位及重启保留选择的速度。支持新调度能力时，定位、重新模拟与完整验证
默认使用 4×，结束后恢复播放速度。声音保持原速度，不做音频变速。

关闭录制开关后，输入格可水平拖绘：首格决定本笔按下/松开，跨过的帧应用相同值。
松开或失去鼠标捕获时完成一笔；Ctrl+Z 一次撤销整笔，Ctrl+Y 可重做。

展开“编辑帧输入”，在“…”菜单中选择插入、末尾追加或删除区间。
插入数量使用下方数字框；删除使用起止帧（含两端）。插入的帧默认全部松开，
至少保留一帧。书签随帧移动，删除时暂时移除，撤销时恢复；插入帧上新增的书签也支持撤销/重做恢复。

结构修改是未执行草稿：应用修改（F5）前不会把新帧号当作旧游戏画面播放/定位。
应用成功后，保存 .krec 即包含新的长度、输入、真实 RNG 和校验值。
恢复上次覆盖仍可找回旧录制及草稿。旧录制和第一版 .ktas 草稿可读取，
新版 .ktas 使用版本 2 保存帧来源映射，原始录制保留不变。
